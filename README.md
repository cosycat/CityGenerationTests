# 24fs_iit07_Prozedurale Welten und automatische Erzeugung von Content

Bachelor Thesis project by Toni Lozancic and Flavia Brogle

## Abstract

Learning to drive is essential, but the traditional method of on-road instruction is both costly and
time consuming. The use of virtual reality for driver training presents a compelling alternative.
However, creating a realistic virtual environment suitable for student driving training requires
sophisticated road layouts and dynamic traffic simulations.
This thesis investigates how to combine existing technologies in settlement and road generation,
traffic simulation, and 3D visualization to build a comprehensive virtual road network that could
with further work be used for driver training. We employ a modular approach where different
agents automatically contribute specific elements to the virtual road network. This road network
and the world is visualized in 3D, enabling real-time observation as it is being constructed.
