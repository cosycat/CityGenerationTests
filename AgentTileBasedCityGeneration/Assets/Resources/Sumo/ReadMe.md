# Sumo

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python3 traciConnector.py
```

## Combined

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && clear && python3 traciConnector.py
```
