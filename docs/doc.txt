# AP 2

## Ideas

- The world is still tile based (marking water, land, etc.)
- The roads are "semi"-disconnected from the grid (not purely based on 4-neighboorhood)
- Lechner et al. ideas are used again, maybe with some adaptations but without the property developers
- For properties, maybe use method from Emilien et al.
- Using a graph to represent the road network. The edges could have information like road type, speed limit, elevation

## Challenges

- What happens when there is an intersection? -> Split edges into new part and place a new point
- How to find intersections?
    - World tiles store attribute that a tile has a road (and stores the reference to the road?). When reaching such a tile, calculate the line intersection
    - Sweep line algorithm
- How to find lines which are nearby (or how to find the closest line from a given position)?
    - Bounding boxes (optionally with some padding, to allow for some distance between roads)
    - https://en.wikipedia.org/wiki/K-d_tree
